# CareerAI Deployment Guide

This guide provides tested, error-free instructions to deploy CareerAI on **Vercel** and **Render**.

---

## Option 1: Render Full-Stack (Recommended — Free & Easiest)

Deploy the entire app (React frontend + Node/Express backend) in a single service on Render. No CORS issues, single URL, zero configuration.

### Steps:
1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "Configure project for deployment"
   git push origin main
   ```
2. Log in to [Render.com](https://dashboard.render.com).
3. Click **New +** > **Blueprint** (or **Web Service**).
4. Connect your GitHub repository (`careenai`).
5. Render will automatically detect `render.yaml`.
6. Provide the environment variables:
   - `MONGO_URI`: Your MongoDB Atlas connection string.
   - `AI_API_KEY`: Your Groq or Anthropic API key (`gsk_...`).
   - `JWT_SECRET`: Auto-generated by Render or a 32+ character string.
7. Click **Apply / Create Web Service**.
8. Render will run:
   - Build: `npm run render-build` (installs deps, builds frontend, seeds DB)
   - Start: `npm run render-start` (starts Express API and serves the React frontend)
9. Your app is live at `https://<your-service-name>.onrender.com`!

## Option 2: Vercel (Frontend) + Render (Backend)

For global edge CDN caching of the React frontend on Vercel and the backend running on Render.

### Step 1: Deploy Backend on Render
1. In Render, click **New +** > **Web Service**.
2. Connect your repo.
3. Configure:
   - **Name**: `careerai-api`
   - **Root Directory**: `server`
   - **Runtime**: `Node`
   - **Build Command**: `npm install && npm run seed:admin && npm run seed:questions`
   - **Start Command**: `npm start`
4. Add Environment Variables:
   - `PORT`: `10000`
   - `NODE_ENV`: `production`
   - `MONGO_URI`: Your MongoDB Atlas URI
   - `JWT_SECRET`: Your secret key
   - `CLIENT_URL`: `https://*.vercel.app` (or your Vercel domain)
   - `AI_API_KEY`: Your Groq API key
   - `AI_API_URL`: `https://api.groq.com/openai/v1`
   - `AI_MODEL`: `qwen/qwen3.8-27b`
5. Click **Create Web Service**. Note your backend URL (e.g., `https://careerai-api.onrender.com`).

### Step 2: Deploy Frontend on Vercel
1. Log in to [Vercel](https://vercel.com).
2. Click **Add New...** > **Project**.
3. Import your GitHub repository (`careenai`).
4. In the Project Configuration:
   - **Framework Preset**: `Vite`
   - **Root Directory**: `client` (or leave as `./` — root `vercel.json` will handle it)
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. In **Environment Variables**, add:
   - `VITE_API_URL`: `https://careerai-api.onrender.com/api` (replace with your Render backend URL)
6. Click **Deploy**.
7. Your frontend is live on Vercel with global CDN and automated SSL!

## Environment Variables Reference

| Variable | Description | Example |
| :--- | :--- | :--- |
| `PORT` | API Server Port | `5000` / `10000` |
| `NODE_ENV` | Environment | `production` |
| `MONGO_URI` | MongoDB Atlas Connection String | `mongodb+srv://user:pass@cluster.mongodb.net/?appName=Cluster0` |
| `JWT_SECRET` | Secret for signing JWTs | `6e13fd...` |
| `JWT_EXPIRES_IN` | Token expiration duration | `7d` |
| `CLIENT_URL` | Allowed frontend origin | `*` or `https://your-app.vercel.app` |
| `AI_API_KEY` | Groq / Anthropic API Key | `gsk_...` |
| `AI_API_URL` | AI API Base URL | `https://api.groq.com/openai/v1` |
| `AI_MODEL` | AI Model ID | `qwen/qwen3.8-27b` |
| `AI_FALLBACK_MODEL` | AI Fallback Model | `openai/gpt-oss-120b` |
| `VITE_API_URL` | Client API endpoint | `https://your-api.onrender.com/api` |
